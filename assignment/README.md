# Online Store Project

## 📌 Project Description
This is an e-commerce web application built with vanilla JavaScript, HTML5, and CSS. The project features product cataloging, category filtering, search functionality, sorting options, and a fully functional shopping cart using localStorage.

## 🚀 How to Run the Project
1. Open the project folder in Visual Studio Code.
2. Use the *Live Server* extension (right-click index.html and select Open with Live Server).

## 🔌 API Endpoints Used
The application fetches products, categories, and search results dynamically from an external REST API.
